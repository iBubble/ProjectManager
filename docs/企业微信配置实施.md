# 政府信息中心大模型智能信息化项目管理系统 - 企业微信消息推送配置实施指南

本文档详细说明如何配置与开发企业微信消息推送服务，将 [政务智管平台](file:///root/www/ProjectManager/docs/%E9%9C%80%E6%B1%82.txt) 的项目节点预警、大模型研判风险以及待办提醒无缝推送至使用人的**普通微信**中。

---

## 一、 整体架构与接收原理

- **推送载体**：企业微信自建应用消息 / 微信互通群机器人 Webhook。
- **消息终端**：支持直接发送到用户的**普通微信**（无需强制安装企微 APP，无需申请微信公众号）。
- **接收原理**：用户使用普通微信关注本单位企业微信插件（或扫码关注企微应用）后，企业微信通过官方打通接口将消息同步投递至普通微信聊天列表。

---

## 二、 阶段一：企业微信后台配置（准备工作）

### 1. 注册与登录控制台
1. 管理员登录 [企业微信管理后台](https://work.weixin.qq.com/)。
2. 确保单位企业微信已完成基本注册与组织架构导入。

### 2. 创建系统自建应用
1. 进入【应用管理】 -> 【自建】 -> 点击【创建应用】。
2. **应用名称**：`政务智管预警助手`。
3. **应用 Logo**：上传政务/项目管理相关图标。
4. **可见范围**：选择信息中心全体人员、各项目负责人、科室领导及分管领导。

### 3. 保存核心凭证参数
在管理控制台中记录以下 3 个关键参数（系统后端配置文件需使用）：
- **`CorpID`**：企业唯一标识（在【企业信息】底部查看）。
- **`AgentID`**：自建应用的唯一数字 ID（在刚创建的应用详情页查看）。
- **`Secret`**：自建应用的调用密钥（在应用详情页点击查看并发送至手机）。

### 4. 配置微信端接收（关键步骤）
1. 在企业微信后台进入【微信插件】页面。
2. 获取“邀请关注二维码”并发送给单位领导与项目成员。
3. 用户使用**普通微信扫码关注**。
4. **效果**：完成关注后，即使手机未安装企微 APP，所有推送消息将直接以卡片形式呈现在**普通微信**的聊天列表中。

## 三、 阶段二：系统后端代码开发（Go 语言实现）

本系统（ProjectManager）后端基于 Go 语言开发，实现微信推送需要以下 3 个核心步骤：

### 1. 获取并缓存 `access_token`
企业微信 API 要求所有请求必须携带 `access_token`（有效期 7200 秒）：

```go
// GetWeChatAccessToken 获取企业微信 API 调用凭证
func GetWeChatAccessToken(corpID, secret string) (string, error) {
    url := fmt.Sprintf("https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=%s&corpsecret=%s", corpID, secret)
    resp, err := SafeHTTPClient(10 * time.Second).Get(url)
    if err != nil {
        return "", err
    }
    defer resp.Body.Close()

    var result struct {
        ErrCode     int    `json:"errcode"`
        ErrMsg      string `json:"errmsg"`
        AccessToken string `json:"access_token"`
        ExpiresIn   int    `json:"expires_in"`
    }
    if err := json.NewDecoder(resp.Body).Decode(&result); err != nil {
        return "", err
    }
    if result.ErrCode != 0 {
        return "", fmt.Errorf("获取 access_token 失败: %s", result.ErrMsg)
    }
    return result.AccessToken, nil
}
```

### 2. 封装卡片消息发送 API (`SendWeChatTemplateCard`)
发送符合政务预警规范的模板卡片消息：

```go
// SendWeChatTemplateCard 发送预警卡片消息到用户微信
func SendWeChatTemplateCard(accessToken string, agentID int, toUsers []string, title, projectName, alertLevel, aiAnalysis, targetURL string) error {
    url := fmt.Sprintf("https://qyapi.weixin.qq.com/cgi-bin/message/send?access_token=%s", accessToken)

    payload := map[string]interface{}{
        "touser":  strings.Join(toUsers, "|"),
        "msgtype": "template_card",
        "agentid": agentid,
        "template_card": map[string]interface{}{
            "card_type": "text_notice",
            "source": map[string]string{
                "desc": "政务智管・节点自动预警",
            },
            "main_title": map[string]string{
                "title": title,
            },
            "sub_title_text": fmt.Sprintf("项目名称：%s", projectName),
            "horizontal_content_list": []map[string]string{
                {"keyname": "预警级别", "value": alertLevel},
                {"keyname": "AI 风险分析", "value": aiAnalysis},
            },
            "jump_list": []map[string]interface{}{
                {
                    "type":  1,
                    "url":   targetURL,
                    "title": "查看项目全部资料与整改建议",
                },
            },
            "card_action": map[string]interface{}{
                "type": 1,
                "url":  targetURL,
            },
        },
    }

    jsonBytes, _ := json.Marshal(payload)
    resp, err := SafeHTTPClient(10 * time.Second).Post(url, "application/json", bytes.NewBuffer(jsonBytes))
    if err != nil {
        return err
    }
    defer resp.Body.Close()
    return nil
}
```

### 3. （可选方案）微信群机器人 Webhook 推送
对于项目监理组群、第三方供应商群，直接在微信群设置中添加“群机器人”，后端无需 `access_token` 直接向 Webhook 地址 POST 提交 JSON 消息即可。

## 四、 阶段三：预警触发与逻辑联动

### 1. 每日定时倒计时触发（时间条件）
- **触发机制**：系统每日定时扫描数据库中的付款节点、竣工验收日、质保到期日。
- **对应级别**：
  - 🔵 提前 7 天：推送给项目负责人（蓝色提醒）。
  - 🟡 当日到期：推送给项目负责人与管理员（黄色提醒）。
  - 🔴 已经逾期：推送给分管领导、管理员与负责人（红色风险预警）。

### 2. 大模型文件解析触发（事件条件）
- **触发机制**：用户上传新的监理周报、需求变更单或会议纪要。
- **AI 研判**：大模型解析出“进度严重滞后”或“未经审批超概算变更”时，立即触发 `SendWeChatTemplateCard` 主动推送给相关领导。

---

## 五、 阶段四：联调测试与验收

1. **绑定用户微信 ID**：在系统【系统管理】->【用户管理】界面中，填入各用户的企微账号 / 绑定 ID（如 `wx_liu_staff`）。
2. **连通性握手测试**：在后台点击“测试微信连通性”，验证目标普通微信是否成功弹出消息卡片。
3. **已阅与直达跳转**：点击微信卡片中的项目直达链接，验证是否能直接跳转至对应的项目档案与 AI 分析页面。
